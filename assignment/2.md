Write a Python program that asks the user to enter a word and then enter a letter.

Your program should:

Check if the user has entered exactly one letter.

If more than one character is entered, display:

"Invalid input! Please enter only one letter."

If the input is valid, check whether the letter is present in the word.

Display:

"Letter found!" if the letter exists in the word.

"Letter not found!" if the letter does not exist in the word.

Note:

Use only conditional statements and operators.
